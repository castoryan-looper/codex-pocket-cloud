Codex Pocket 设备配置

支持 USB 调试配置和设备 Wi-Fi 网页。语音与任务通过 Wi-Fi 连接云端。

USB 连接

使用 USB 数据线连接设备，在 Chrome 或 Edge 中点击连接并选择 ESP32 串口。配置数据通过 USB 直接传输，不发送到服务器。

断开后会释放串口，便于刷写固件或使用其他工具；未保存的表单内容会保留。

Wi-Fi

扫描时设备 Wi-Fi 会短暂断开，完成后自动重连。

手动输入隐藏网络
已记住的 Wi-Fi（最多 8 个）
选择已记住的网络时密码留空会保留。第 9 个会替换最久未使用的网络，当前正在连接的网络会尽量保留。

保存当前表单中的全部配置，设备重启后生效。

云端服务连接

设备通过 Wi-Fi 连接云端 WSS 服务。配置通过 USB 保存在设备中，连接密钥不会发送到网页服务器。

蓝牙旋钮

等待设备状态

已配对设备：等待读取

按一下旋钮唤醒，断开其他主机后搜索，选择设备并配对。列表仅显示 BLE 广播，最多20个；HID标识不保证兼容，配对后会进一步检查。默认音量增减为旋转，静音为按下，按住旋转的亮度减/增为返回/换组。旋转选择，按下确认；执行任务须先选中“执行这条”。

按键与屏幕

旋转浏览不逐格响；录音期间不播放提示音。修改后保存并重启生效。

设备重启后如断开，请点击“连接 USB 设备”重新授权。
